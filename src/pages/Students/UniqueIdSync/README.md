# 📝 Unique ID (UID) Sync — Page Blueprint & Architecture

This directory contains the **Unique ID Sync** sub-module, managing 17-digit government assigned CRVS student UIDs required by national boards.

---

## 🎨 1. Frontend Wires & Interface

*   **Roster Table:** Identifies missing student UIDs in a class, showing a colored warning tag.
*   **Sync UID Modal:** Validates and saves the 17-digit numeric unique ID directly.
