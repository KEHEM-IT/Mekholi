# 📝 Promote & Transfer — Page Blueprint & Architecture

This directory contains the **Promote & Transfer** sub-module, managing sessional year-end student grade promotions and inter-campus transfer clearances.

---

## 🎨 1. Frontend Wires & Interface

*   **Sessional Mass Promotion Controls:** Select source class and target year, automatically promoting all active candidates to the next grade level with a single click.
*   **Transfer Out Modal:** Clears student enrollment, sets section to `TC Out` to log Transfer Certificates, and deactivates the profile locally.
