# 📝 Student ID Cards — Page Blueprint & Architecture

This directory contains the **Student ID Cards** sub-module, rendering beautiful, dark-themed sessional student ID card certificates on-the-fly.

---

## 🎨 1. Frontend Wires & Interface

*   **Roster Table:** Select target class, click "Generate ID" to preview student cards.
*   **ID Card Mockup Card:** Renders student avatars, IDs, classes, sections, roll numbers, and blood groups in a clean layout with quick printing triggers.
