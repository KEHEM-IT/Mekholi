# 📝 Behavior & Discipline — Page Blueprint & Architecture

This directory contains the **Behavior & Discipline** sub-module, managing point-based merit-demerit behavior tracking.

---

## 🎨 1. Frontend Wires & Interface

*   **Roster Table:** Tracks behavioral points per student (default 100). Highlights scores under 100 in red (demerits), and scores above 100 in green (merits).
*   **Behavior Log Modal:** Allows class teachers to reward positive behavior (+5 points) or log uniform/attendance infractions (-5 points), with description remarks.
